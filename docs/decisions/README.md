# 架构决策记录（ADR）

本目录记录**影响面大或不可逆**的技术选择。一条决策一个文件，编号递增，**永不修改已接受的 ADR**——改变主意就新增一条，并在新 ADR 里注明它取代了哪一条。

判断标准：**如果半年后有人会问「为什么当初不那样做」，就需要一条 ADR。**

```markdown
- **影响面**：（协议 / 存储 / 接入 / 权限 …）

## 背景

（面临什么问题，有哪些约束。不要写结论。）

（决定了什么。一句话能说清最好。）

## 后果

- …

**负面 / 代价**
- …

（负面项必须写。只写优点的 ADR 不成立。）

## 备选方案

| 方案 | 放弃理由 |
|---|---|
| … | … |
```
